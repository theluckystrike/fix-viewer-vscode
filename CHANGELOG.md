# Changelog

## 0.1.0

- First release: FIX 4.2, 4.4, 5.0 and FIXT.1.1 trading message files (`.fix`, `.fixlog`) in a read-only viewer, parsed locally with plain JavaScript and nothing to install.
- Message table with sequence number, sending time, decoded message type, session, symbol, side, quantity, price, client order ID and order status.
- Tag inspector with standard FIX tag names, enum value labels, BodyLength checks and CheckSum checks.
- Zovo Pro tools with 1 free try each: session sequence-gap and checksum audit report, CSV and JSON export, and two-file order lifecycle comparison. Get Zovo Pro first shows what Pro includes and the tries left, in an editor tab.
